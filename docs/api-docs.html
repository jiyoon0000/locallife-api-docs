적성 검사 시작

AI 기반 적성 검사를 시작합니다. 온보딩 시 첫 검사는 제한 없이 가능하며, 마이페이지에서는 최대 5회까지 가능합니다. 기존 진행 중인 테스트는 초기화됩니다.

Authorizations:
bearerAuth

Responses

Generated server url

http://localhost:8080/ai/aptitude/test/start

  • 201
Content type
application/json
{
  • "status": 0,
  • "message": "string",
  • "data": { }
}
